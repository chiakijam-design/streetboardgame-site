# 広告掲載位置ポリシー

Streetboardgameで広告を導入する場合、表示できる場所は次の4場面だけです。

| 許可する場面 | 表示位置 |
| --- | --- |
| 結果を表示した後 | 結果画像、答え合わせレポート、役割交代CTA、共有操作より後 |
| 問題ライブラリを長時間閲覧した後 | 長時間閲覧が成立した後。問題カードの間には挿入しない |
| 新しい診断を作り始める前 | 作成開始操作の後、問題作成画面へ入る前 |
| 理解度ボード閲覧後 | 理解度ボードの内容を確認できた後 |

## 表示しない場所

- 問題作成中
- 出題者の正解登録中
- 回答者の回答中
- 答え合わせの途中
- LIVEの作成・参加・回答・進行中
- 決済・購入・返金の画面
- ログイン・認証・同意確認の画面
- 運営管理画面

`src/ads/placement-policy.js` の許可リストにない広告位置は、既定で拒否します。広告事業者のスクリプトを導入する際は、必ず `canDisplayAd` を通して表示可否を判定してください。

広告事業者をまだ選定していないため、現時点では空の広告枠や広告スクリプトを画面へ追加しません。
