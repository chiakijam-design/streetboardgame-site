# 広告掲載位置ポリシー

Streetboardgameで広告を導入する場合、表示できる場所は次の4場面だけです。

| 許可する場面 | 表示位置 |
| --- | --- |
| 結果を表示した後 | 結果画像、答え合わせレポート、役割交代CTA、共有操作より後 |
| 問題ライブラリを長時間閲覧した後 | 長時間閲覧が成立した後。問題カードの間には挿入しない |
| 新しい診断を作り始める前 | 作成開始操作の後、問題作成画面へ入る前 |
| 理解度ボード閲覧後 | 理解度ボードの内容を確認できた後 |

## 表示しない場所

- 問題作成中
- 出題者の正解登録中
- 回答者の回答中
- 答え合わせの途中
- LIVEの作成・参加・回答・進行中
- 決済・購入・返金の画面
- ログイン・認証・同意確認の画面
- 運営管理画面

`src/ads/placement-policy.js` の許可リストにない広告位置は、既定で拒否します。広告事業者のスクリプトを導入する際は、必ず `canDisplayAd` を通して表示可否を判定してください。

## Google AdSense の実装（2026-11-15）

- 4場面の実際の位置：
  - 結果を表示した後：結果画像の準備が終わった結果画面で、結果画像・答え合わせ・役割交代・共有・理解度ボードの**すべての下**（全問回答済みのときだけ。1〜10問のどれでも可）。
  - 問題ライブラリを長時間閲覧した後：/challenge/library で30秒以上たち、かつページの6割以上までスクロールした後、ライブラリの**一番下**。カードの間には入れない。
  - 新しい診断を作り始める前：/challenge の最初の画面（名前入力）の**一番下**。問題作成・回答の画面には出さない。
  - 理解度ボード閲覧後：/challenge/ranking でボードを表示した後、ページの**一番下**。
- 広告は遊びの画面の外側（`#challenge-app` の直後）に1つだけ置き、場面が変わったときだけ入れ替える。画面の再描画で広告を読み直さない（無効なアクセス扱いを防ぐ）。
- 広告のプログラム（adsbygoogle.js）は、許可された場面で初めて広告を出すときにだけ読み込む。
- 出すのは**日本からの接続だけ**。ほかの地域（欧州・英国など）は、Google 認定の同意画面を入れるまで出さない。
- 広告の上に「広告」と表示する。
- Worker（`src/ads/adsense-config.js`）は、広告を出すときだけ CSP に Google の広告配信先（script・frame・connect・img）を足し、ページを共有キャッシュさせない。

### 合格後の手順（本人の AdSense 操作が必要）
1. AdSense の管理画面で、このサイトの**自動広告はオフ**のままにする（自動広告は4場面の決まりを守れないため）。
2. 「広告ユニット」→「ディスプレイ広告」でユニットを作る（4つ作るか、1つを4場面で共用）。表示される `data-ad-slot` の数字を控える。
3. `wrangler.jsonc` の `ADSENSE_ENABLED` を `"true"` にし、`ADSENSE_SLOT_RESULT`・`ADSENSE_SLOT_LIBRARY`・`ADSENSE_SLOT_BEFORE_CREATE`・`ADSENSE_SLOT_BOARD` に数字を入れて公開する（数字のない場面には出さない）。
