# Cloudflare Images月次監視

LIVE運営コンソールの「Images月次変換」で、アプリが実行した月間変換数を確認する。

- 新規画像1枚につき通常2変換として記録する。
- 4,000変換（月約2,000枚）で黄色警告を表示する。
- 4,800変換（月約2,400枚）で赤色警告を表示し、`LIVE_OPS_ALERT_WEBHOOK_URL`へ通知する。
- Cloudflare Imagesが`9422`を返した場合は月1回の重大通知を送り、非公開R2へ保存した元画像で結果画像生成を継続する。
- 利用者には「画像処理が混み合っています」と表示し、企画作成や購入処理を止めない。

アプリ内カウンターは早期警告用である。請求判断ではCloudflare Dashboardの`Images Transformed`を正として照合する。
