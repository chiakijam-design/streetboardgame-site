ملخص مبسط للأطفال

  • استخدم فقط الأسئلة والصور والرسوم والشعارات التي أنشأتها أو أُذن لك باستخدامها.
  • لا تدخل أسماء حقيقية أو أسماء مدارس أو معرّفات تواصل أو هواتف أو عناوين أو معلومات تعرّف بك أو بغيرك.
  • لا يمكنك نشر أسئلة ضارة أو محتوى جنسي أو تنمر أو هجوم على المظهر أو تمييز.
  • قد يراجع المشغّل الأسئلة المفعّل فيها «اسمح للآخرين باستخدامها» ويعدّلها ويضيفها إلى المكتبة.

هذا ملخص مبسط. تسود الإرشادات الكاملة أدناه في التفاصيل الرسمية.

1. المحتوى المشمول

تنطبق هذه الإرشادات على المحتوى التالي الذي ينشئه أو يدخله أو يرسله أو يسجله أو يشاركه أو يبلغ عنه المستخدمون في التحدي العادي وتحدي البث LIVE والميزات المرتبطة في Streetboardgame.

  • نص السؤال و5 خيارات وشروح وفئات وبيانات أخرى
  • أسماء المنشئين ومقدمي البث وحسابات/قنوات البث وأسماء عرض المشاركين وتعليقات لوحة الفهم
  • الصور والصور الشخصية والأفاتار وصور الملفات والشعارات التي يسجلها مقدمو البث المستخدمون للمبيعات المدفوعة عند إتاحة تسجيل الصور
  • بطاقات نتائج مجانية وصور نتائج أصلية مدفوعة عالية الدقة ونص مشاركتها

2. المواد المسموح بها والتحقق من الحقوق

لا يستخدم المستخدمون إلا مواد أنشؤوها أو يملكون حقوقها أو أذن لهم بعرضها وتعديلها وإدراجها في صور النتائج وتقديمها للمشترين ومشاركتها اجتماعياً في الخدمة. مجرد إتاحتها على الإنترنت أو التواصل لا يبيح النسخ أو إعادة الاستخدام بلا قيود.

  • للصور، تحقق من حقوق المصور وحقوق الصورة والخصوصية للأشخاص الظاهرين.
  • إذا ظهرت رسوم أو شعارات أو شخصيات أو منتجات أو مساحات داخلية أو مشاركون أو عناصر مشابهة، فتحقق من أذونات أصحاب الحقوق والمنظمات والمرافق اللازمة.
  • عند استخدام فن المعجبين أو المواد الجاهزة أو الصور المنشأة بالذكاء الاصطناعي، تحقق من سماح شروط أداة الإنشاء والمواد الأصلية والتكليف والموزع بالاستخدام التجاري هنا والتعديل والإدراج في صور النتائج وتسليمها للمشترين.
  • عند استخدام صور قاصرين أو معلومات تعرّف بهم، احصل على موافقة صريحة من القاصر ووالده أو ولي أمره وأي أطراف لازمة أخرى. لا يجوز تسجيل صور أطفال عراة أو بملابس سباحة أو أثناء الاستحمام أو صور قد تكون جنسية.

3. الأسئلة المخصصة وتقديم المرشحات للنشر

يمكن استخدام الأسئلة المخصصة والمعدلة في الوضع العادي وLIVE. إذا أكملت السؤال مع تفعيل «دع الأصدقاء وغيرهم يعيدون استخدام الاختبار» يُرسل نصه وخياراته للمشغّل لمراجعة النشر. عند التعطيل يمكنك إنشاء اختبارك لكن لا يُقدم السؤال للنشر في المكتبة المشتركة.

يفحص المشغّل ويعدل محتوى مراجعة النشر للأمان والوضوح واتساق الصياغة ومنع التكرار وحماية الحقوق. عند القبول يُتاح للآخرين في مكتبة الأسئلة المشتركة للعادي وLIVE. التقديم لا يضمن النشر؛ يقرر المشغّل القبول أو التعديل أو التعطيل أو الرفض.

4. الترخيص للمشغّل

تبقى حقوق النشر وغيرها في محتوى المستخدم له أو لصاحب الحقوق الأصلي. يمنح المشغّل ترخيصاً مجانياً غير حصري للمحتوى المقدم أو المسجل بقدر تقديم الخدمة وتشغيل الألعاب ومراجعته وتعديله ونشره في المكتبة وإنشاء وعرض وتسليم صور النتائج المجانية والمدفوعة والتنزيلات وإعادة الخدمة ودعم المستخدم وفحص الإساءة وانتهاكات الحقوق.

قد تُقص الصور أو تُغير أحجامها أو تُعالج خلفياتها أو تُدمج بالنص والزخارف أو تُحوّل لصيغ أخرى بحسب الأغراض أعلاه. قد تُعدّل الأسئلة والخيارات للأمان والوضوح والاتساق ومنع التكرار.

لا يشمل الترخيص بيع محتوى المستخدم لجهات ثالثة أو استخدامه لأجل غير محدد لتدريب ذكاء اصطناعي توليدي غير متعلق بالخدمة. لن يستخدم المشغّل المحتوى للإيحاء بتأييد المستخدمين منتجات أو خدمات أو آراء سياسية للغير دون موافقتهم المسبقة.

5. المعلومات الشخصية ومراجعة السلامة

إذا كُشفت نصوص تشبه أسماء حقيقية أو مدارس أو معرّفات تواصل أو هواتف أو عناوين في السؤال أو خياراته لا يُحفظ المرشح ويُطلب التصحيح. تُسجل احتمالات المحتوى الجنسي والتنمر ومهاجمة المظهر والتمييز لمراجعة المشغّل. الكشف التلقائي مساعد ولا يضمن كشف كل المعلومات الشخصية أو انتهاكات الحقوق أو العبارات غير المناسبة.

لا تدخل أسماء حقيقية أو مدارس أو بيانات اتصال أو روابط سرية أو معلومات تعرّفك أو غيرك أو تتبعكما في أسماء المنشئ أو مقدم البث أو المشارك أو تعليقات اللوحة الحرة. يُحظر أيضاً نشر معلومات حياة خاصة عرفتها عن الآخرين كأسئلة أو تعليقات دون موافقتهم.

6. المحتوى المحظور

  • النسخ غير المصرح أو انتحال الهوية أو انتهاك حقوق نشر الآخرين وعلاماتهم وصورتهم/خصوصيتهم وسمعتهم وحقوق الدعاية أو حقوق أخرى
  • استغلال الأطفال جنسياً أو التعبيرات الجنسية الصريحة أو المواد الإباحية الانتقامية أو التصوير المتلصص أو صور وتعبيرات جنسية أخرى دون موافقة
  • محتوى يهدف للتمييز أو التهديد أو التشهير أو التنمر أو مهاجمة المظهر أو كشف المعلومات الشخصية أو المضايقة
  • محتوى يشجع إيذاء النفس أو الأفعال الخطرة أو النشاط غير القانوني أو احتيال الدفع أو الخداع أو دخول الحسابات دون إذن
  • تأييدات أو ارتباطات أو سوابق أو بيانات حساب/قناة بث زائفة تضلل مقدمي البث أو المشاهدين أو غيرهم
  • محتوى آخر ينطوي على خطر معقول لانتهاك الحقوق أو الإضرار بأمان المستخدمين، خاصة القاصرين

7. المرشحات المنشأة تلقائياً والمرشحات المستندة إلى معلومات خارجية

عند تقديم تكامل YouTube أو إنشاء تلقائي آخر لا تُضمن الدقة وسلامة الحقوق والملاءمة حتى للأسئلة المرشحة المبنية على معلومات عامة أو مأذون بجلبها. قبل النشر أو الاستخدام يفحص المنشئ أو مقدم البث السؤال وكل الخيارات الخمسة ويصحح أو يزيل التضليل والمعلومات الشخصية والمواضيع الحساسة والنسخ غير المصرح.

تُنشأ تقارير مراجعة الإجابات تلقائياً داخل الخدمة من الإجابات المتطابقة والمختلفة. لا تُرسل الأسئلة والإجابات حالياً لخدمات ذكاء اصطناعي خارجية لهذا الغرض.

8. صور صانع البث وصور النتائج

إذا أُتيح تسجيل صور مقدم البث تُحفظ خاصة ولا تُستخدم في شاشات LIVE أو المعاينات المجانية أو صور النتائج المدفوعة قبل اعتماد المشغّل. تُحذف المرفوضة. قد تُعلق المعتمدة أو تُراجع أو تُحذف إثر شكاوى حقوق أو مخاوف أمان أو بلاغات.

تُحذف الصور المسجلة والمعاينات عموماً خلال 24 ساعة بعد نهاية LIVE وصور النتائج المدفوعة بعد 30 يوماً. قد تُحفظ المعلومات اللازمة للاسترداد أو انتهاكات الحقوق أو الاحتيال أو الحفظ القانوني أو النزاعات بقدر الحاجة. للمدد التفصيلية راجعسياسة الخصوصيةسيتم الالتزام بها.

يجوز حفظ بطاقات/صور النتائج الشخصية للاستخدام الخاص ومشاركتها على التواصل أو تطبيقات الرسائل. تُحظر إعادة البيع أو استخراج المواد أو صنع بضائع أو استخدامها للإعلان أو تعديلات تؤذي أصحاب الحقوق أو توزيعها باسم الغير. اتبع شروط منصة المشاركة أيضاً.

9. المراجعة والبلاغات والإخفاء الفوري

يراجع المشغّل الأسئلة المقدمة والصور المسجلة وقد يرفضها أو يعدلها أو يعطلها أو يمتنع عن قبول الصور عند مخالفات فعلية أو محتملة. لا تضمن المراجعة أو الموافقة الدقة أو المشروعية أو سلامة الحقوق.

يمكن الإبلاغ عن الأسئلة المخصصة المنشورة من شاشة اللعبة. تُخفى الأسئلة المبلغ عنها فوراً حتى اكتمال المراجعة ثم تُعاد أو تُعدّل أو تُعطل أو تُحذف بحسب إعادة المراجعة. تُحظر البلاغات الكاذبة وإساءة ميزة الإبلاغ.

10. الإبلاغ عن انتهاك الحقوق وطلب الإزالة

أصحاب حقوق النشر والأشخاص المصوّرون والأوصياء وأصحاب الحقوق الآخرون،نموذج التواصلقدم عبر وسيلة الاتصال الرابط أو رمز الانضمام والمحتوى والحقوق المعنية وعلاقة الشاكي بصاحب الحقوق والإجراء المطلوب. لا ترسل أرقام بطاقات كاملة أو رموز أمان أو معلومات غير لازمة. يشرح المشغّل فردياً إذا لزم إثبات الهوية أو ملكية الحقوق.

بحسب الشكوى قد يخفي المشغّل المحتوى مؤقتاً أو يعلق المبيعات أو يطلب وثائق أو يعدل أو يحذف المحتوى أو يقدم للمشتري بديلاً أو استرداداً أو يحجز توزيعات مقدم البث أو يتخذ إجراءات لازمة. يتعاون المستخدمون في فحص الوقائع ووثائق الحقوق للأسئلة والمواد المقدمة.

11. العلاقة بالخدمات الخارجية

لا يقدم هذه الخدمة أو يرعاها أو يؤيدها YouTube أو Google أو Instagram أو LINE أو X أو الخدمات الخارجية الأخرى أو الجهات التابعة لها. عند مشاركة المحتوى خارجياً اتبع شروطها ومتطلبات العمر وقواعد الحقوق.
