儿童简明摘要

  • 我们使用输入的名字、题目、答案、得分等信息来运行游戏。
  • 是否上榜由你选择。不发布也可作答、核对答案及查看结果。
  • 勿输入真实姓名、学校、地址、电话等不愿公开的信息。
  • 仅在发布选项开启时，自定义问题才会发送给运营方审核。
  • 疑似真实姓名或联系方式的内容自动检查，不当题目举报用于安全审核。
  • 10–12岁用户必须与监护人共同使用。未满18岁用户付款前须获得监护人同意。

这是简化摘要。信息处理详情以以下完整隐私政策为准。

1. 适用范围与经营者

本政策适用于查看或使用Streetboardgame网站、普通挑战、LIVE直播挑战、自定义题目、付费及相关功能（统称“本服务”）的所有用户。

个人信息处理者为Streetboardgame运营者Tomoaki Hirakawa（“运营者”）。本政策中“用户信息”指与服务相关收集、生成或存储的信息；“个人信息”按日本《个人信息保护法》第2条第1款定义。

2. 收集的信息

在以下范围收集用户输入提交及使用时自动生成的信息。

  • 邀请大家来试：创建者昵称、挑战者输入的了解度榜昵称、所选题目、答案、一致题数、自动称号及答案回顾报告、榜单公开同意时间、创建和作答时间
  • 自定义问题发布申请：用户通过可选复选框同意提交的题目文字、选项、来源模式、提交时间、自动审核标记及防滥用IP哈希
  • 举报问题：被举报题目、举报理由、可选详情、举报时间及防重复或欺诈举报的IP哈希
  • LIVE：游戏标题、题目和选项、预定日期时间、参与者昵称、投票和答案、结果、房间操作历史；选择YouTube集成时还包括频道URL、ID及名称、公开视频标题、描述、标签，以及通过Google认证授权的公开视频字幕
  • LIVE 主播注册（用于付费销售）：姓名及业务资料、联系方式、直播账户/频道信息、登记图片、邀请发出/使用/撤销时间、Stripe Connect账户ID及收入/退款/转账记录
  • 合同同意：条款版本、同意时间、IP地址、Connect账户ID和设备/浏览器信息
  • 购买：商品、价格、购买时间、Stripe付款/客户/收据标识、Stripe收集的买家邮箱及下载状态。运营者D1仅保存用于恢复购买访问检查的单向HMAC，不保存明文邮箱。运营者服务器不保存卡号。
  • 咨询与访问：姓名、邮箱、咨询内容、IP地址、Cookie、访问页面、来源、设备信息及错误日志

卡号、安全码、Google密码、访问令牌及刷新令牌不保存在运营者数据库。IP哈希不直接显示身份，但因用于检测重复及滥用，按安全管理对象处理。

4. 可见范围与向其他用户分享

  • 了解度看板：上榜自愿。仅向同一测验参与者显示同意者的昵称及一致答案数量，不带评论。未同意者不上榜。
  • 组织者答案管理：单题答案显示给持有秘密组织者URL的创建者。该URL不向作答者公开。
  • 直播：启用各选项数量时显示无姓名汇总。各观众看自己答案、正确性及结果卡。
  • 自定义问题：同意公开审核后提交的题目和选项，可在运营者审核编辑后发布到共用题库供他人使用。未提交者不为此目的公开。

如题目或选项检测到疑似真实姓名、学校、社交账号ID、电话或地址，公开候选不保存并要求提交者修改。疑似性内容、霸凌、外貌攻击或歧视会附审核标记保存供运营者检查。

5. YouTube API Services

服务可能使用YouTube API Services，并非由YouTube、Google或关联方提供、赞助或认可。

选择YouTube集成时，公开频道及视频信息用于验证频道和生成候选题。主播选择Google认证后，获取其管理的过去一年最多8个公开视频字幕，主要按观看量并兼顾新近程度排序，生成反映真实言论和场景的题目。处理后撤销Google访问令牌。不保存登录凭据、密码、访问或刷新令牌。YouTube功能受以下约束：YouTube服务条款和Google隐私政策适用。

用户Google安全设置可在此断开集成。删除请求涉及的数据会删除，法律要求保留者除外。

7. 向第三方披露

除以下情况外，运营方不向第三方提供个人数据。

  • 根据本人指示或同意公开了解度榜、自定义题目或其他信息时
  • 需外包本服务的运营、支付、咨询处理、分析或其他工作时
  • 因合并、业务转让或其他业务承继而披露
  • 收到法院、警方、税务机关或其他公共机构依法提出的合法要求时
  • 保护生命、身体、财产或用户及第三方权利、安全所必要且难以取得同意时，或法律允许的其他情况

LIVE主播通常获得销售、退款及收入分配所需的汇总信息，而非可识别个别买家的信息。个人或统计信息不出售给广告商、数据卖家或AI开发者。

8. 统计信息

可用非识别性游玩、使用、错误等汇总改善质量、考虑参与限额、防欺诈和题目热门统计。昵称、单人答案、IP排除或汇总，不重新识别。

10. Cookie与分析

服务使用Cookie、localStorage、sessionStorage等维持功能、恢复进度、了解使用及改善服务。可在浏览器禁用或删除Cookie及网站数据，但恢复进度、参与者认证等功能可能不可用。

Google Analytics 4收集页面浏览、来源、设备和浏览器信息及互动事件。姓名、邮箱、题目和答案内容不作为GA4事件参数发送。Google的信息处理方式见Google隐私政策可在此查看。

Microsoft Clarity收集访问页面、设备/浏览器、点击、滚动和屏幕互动信息，通过热图及会话回放改善易用性。Clarity Cookie已禁用，所有屏幕文字严格遮蔽，因此姓名、邮箱、题目和答案内容不发送给Clarity。Microsoft的信息处理方式见Microsoft隐私声明可在此查看。

11. 安全管理

采用管理双重认证和短会话、游戏与购买历史D1分离、私密R2、Content Security Policy、加密通信、权限分离、过期数据自动删除及日志监控。用户也须防止秘密URL和参与代码泄露。

发现个人数据泄露或疑似泄露时，会停止访问、保全证据、判断影响并联系受托方。依法需要时向日本个人信息保护委员会报告，并通知受影响人士。

12. 披露、更正、暂停、删除等

依法请求告知所持个人数据用途、披露、更正、增补、删除、暂停、清除、停止第三方披露等事项，请通过联系表单请通过此渠道联系。我们会检查相关信息、请求措施及联系方式，进行必要身份验证并依法回应。

依法须保留的交易记录、保护你或他人权利所需记录，或游戏中立即删除会严重影响其他参与者的信息，可能无法满足全部或部分请求。会在法律允许范围说明原因。

13. 未成年人

未满18岁的用户，未成年人使用政策使用前请让监护人审阅此政策并取得必要同意。10–12岁用户须在监护人监督下使用。尤其勿在昵称、题目、选项等输入真实姓名、学校名、社交账号ID、电话、地址或其他可识别、追踪个人的信息。

监护人可通过以下方式请求披露、更正、暂停使用或删除子女的信息联系表单可通过此渠道请求。回应前会验证你与孩子或监护人的关系。

14. 在日本境外处理

使用Cloudflare、Stripe、Google、YouTube、Microsoft、Formspree等外部服务可能导致用户信息在日本境外存储或处理。运营者会检查受托方的公开信息、合同及安全措施，并在法律要求时提供接收国家或地区的法律制度和保护措施信息，取得用户或监护人同意。

15. 修改与适用法律

重要变更及日期提前公告。用途、公开范围、第三方境外披露等依法需要时重新同意。适用日本法，争议，条款其中指定的法院拥有一审管辖权。
