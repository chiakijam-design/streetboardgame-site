1. 適用範圍與經營者

本政策適用於查看或使用Streetboardgame網站、一般挑戰、LIVE直播挑戰、自訂題目、付費及相關功能（統稱「本服務」）的所有使用者。

個人資訊處理者為Streetboardgame營運者Tomoaki Hirakawa（「營運者」）。本政策中「使用者資訊」指與服務相關蒐集、產生或儲存的資訊；「個人資訊」按日本《個人資訊保護法》第2條第1項定義。

2. 收集的資訊

在以下範圍蒐集使用者輸入提交及使用時自動產生的資訊。

  • 邀請大家來試：建立者暱稱、挑戰者輸入的了解度榜暱稱、所選題目、答案、一致題數、自動稱號及答案回顧報告、榜單公開同意時間、建立和作答時間
  • 自訂問題發布申請：使用者透過可選核取方塊同意提交的題目文字、選項、來源模式、提交時間、自動審核標記及防濫用IP雜湊
  • 檢舉問題：被檢舉題目、檢舉理由、可選詳情、檢舉時間及防重複或詐欺檢舉的IP雜湊
  • LIVE：遊戲標題、題目及選項、預定日期時間、參與者暱稱、投票及答案、結果、房間操作歷史；選擇YouTube整合時還包括頻道URL、ID及名稱、公開影片標題、描述、標籤，以及透過Google認證授權的公開影片字幕
  • LIVE 實況主註冊（用於付費銷售）：姓名及業務資料、聯絡方式、直播帳戶/頻道資訊、登記圖片、邀請發出/使用/撤銷時間、Stripe Connect帳戶ID及收入/退款/轉帳紀錄
  • 契約同意：條款版本、同意時間、IP位址、Connect帳戶ID和裝置/瀏覽器資訊
  • 購買：商品、價格、購買時間、Stripe付款/客戶/收據識別碼、Stripe蒐集的買家電子郵件及下載狀態。營運者D1僅保存用於恢復購買存取檢查的單向HMAC，不保存明文電子郵件。營運者伺服器不保存卡號。
  • 諮詢與存取：姓名、電子郵件、諮詢內容、IP位址、Cookie、造訪頁面、來源、裝置資訊及錯誤紀錄

卡號、安全碼、Google密碼、存取權杖及更新權杖不保存在營運者資料庫。IP雜湊不直接顯示身分，但因用於偵測重複及濫用，按安全管理對象處理。

不供第三方產品服務AI訓練，不出售或授權個人資訊及非識別統計。將來改變須更新政策並依法說明及取得同意。

4. 可見範圍與向其他使用者分享

  • 了解度看板：上榜自願。僅向同一測驗參與者顯示同意者的暱稱及一致答案數量，不帶留言。未同意者不上榜。
  • 主辦者答案管理：單題答案顯示給持有秘密組織者URL的建立者。該URL不向作答者公開。
  • 直播：啟用各選項數量時顯示無姓名彙總。各觀眾看自己答案、正確性及結果卡。
  • 自訂問題：同意公開審核後提交的題目及選項，可在營運者審核編輯後發布到共用題庫供他人使用。未提交者不為此目的公開。

如題目或選項偵測到疑似真實姓名、學校、社群帳號ID、電話或地址，公開候選不保存並要求提交者修改。疑似性內容、霸凌、外貌攻擊或歧視會附審核標記保存供營運者檢查。

5. YouTube API Services

服務可能使用YouTube API Services，並非由YouTube、Google或關聯方提供、贊助或認可。

選擇YouTube整合時，公開頻道及影片資訊用於驗證頻道和產生候選題。主播選擇Google認證後，取得其管理的過去一年最多8個公開影片字幕，主要按觀看量並兼顧新近程度排序，產生反映真實言論及場景的題目。處理後撤銷Google存取權杖。不保存登入憑證、密碼、存取或更新權杖。YouTube功能受以下約束：YouTube服務條款和Google隱私權政策適用。

使用者Google安全性設定可在此中斷整合。刪除請求涉及的資料會刪除，法律要求保留者除外。

7. 向第三方揭露

除以下情況外，營運方不向第三方提供個人資料。

  • 根據本人指示或同意公開了解度榜、自訂題目或其他資訊時
  • 需委外本服務的營運、付款、諮詢處理、分析或其他工作時
  • 因合併、業務轉讓或其他業務承繼而揭露
  • 收到法院、警方、稅務機關或其他公共機構依法提出的合法要求時
  • 保護生命、身體、財產或使用者及第三方權利、安全所必要且難以取得同意時，或法律允許的其他情況

LIVE主播通常取得銷售、退款及收入分配所需的彙總資訊，而非可識別個別買家的資訊。個人或統計資訊不出售給廣告商、資料賣家或AI開發者。

8. 統計資訊

可用非識別性遊玩、使用、錯誤等彙總改善品質、考慮參與限額、防詐欺和題目熱門統計。暱稱、個人答案、IP排除或彙總，不重新識別。

10. Cookie與分析

服務使用Cookie、localStorage、sessionStorage等維持功能、恢復進度、了解使用及改善服務。可在瀏覽器停用或刪除Cookie及網站資料，但恢復進度、參與者認證等功能可能不可用。

Google Analytics 4蒐集頁面瀏覽、來源、裝置和瀏覽器資訊及互動事件。姓名、電子郵件、題目及答案內容不作為GA4事件參數傳送。Google的資訊處理方式見Google隱私權政策可在此查看。

Microsoft Clarity蒐集造訪頁面、裝置/瀏覽器、點擊、捲動和畫面互動資訊，透過熱圖及工作階段重播改善易用性。Clarity Cookie已停用，所有畫面文字嚴格遮蔽，因此姓名、電子郵件、題目及答案內容不傳送给Clarity。Microsoft的資訊處理方式見Microsoft隱私權聲明可在此查看。

11. 安全管理

採用管理雙重認證及短工作階段、遊戲與購買歷史D1分離、私密R2、Content Security Policy、加密通訊、權限分離、過期資料自動刪除及紀錄監控。使用者也須防止秘密URL和參與代碼洩漏。

發現個人資料外洩或疑似外洩時，會停止存取、保全證據、判斷影響並聯絡受託方。依法需要時向日本個人資訊保護委員會報告，並通知受影響人士。

12. 揭露、更正、暫停、刪除等

依法請求告知所持個人資料用途、揭露、更正、增補、刪除、暫停、清除、停止第三方揭露等事項，請透過聯絡表單請透過此管道聯絡。我們會檢查相關資訊、請求措施及聯絡方式，進行必要身分驗證並依法回應。

依法須保留的交易紀錄、保護你或他人權利所需紀錄，或遊戲中立即刪除會嚴重影響其他參與者的資訊，可能無法滿足全部或部分請求。會在法律允許範圍說明原因。

13. 未成年人

未滿18歲的使用者，未成年人使用政策使用前請讓監護人審閱此政策並取得必要同意。10–12歲使用者須在監護人監督下使用。尤其勿在暱稱、題目、選項等輸入真實姓名、學校名稱、社群帳號ID、電話、地址或其他可識別、追蹤個人的資訊。

監護人可透過以下方式請求揭露、更正、暫停使用或刪除子女的資訊聯絡表單可透過此管道請求。回應前會驗證你與孩子或監護人的關係。

14. 在日本境外處理

使用Cloudflare、Stripe、Google、YouTube、Microsoft、Formspree等外部服務可能導致使用者資訊在日本境外儲存或處理。營運者會檢查受託方的公開資訊、合約及安全措施，並在法律要求時提供接收國家或地區的法律制度及保護措施資訊，取得使用者或監護人同意。

15. 修改與準據法

重要變更及日期提前公告。用途、公開範圍、第三方境外揭露等依法需要時重新同意。適用日本法，爭議，條款其中指定的法院擁有第一審管轄權。
