本ポリシーは、Streetboardgameのウェブサイト、みんなに挑戦してもらうモード、ライブ配信モード、自作問題、有料機能および関連機能（以下「本サービス」）を閲覧または利用するすべての利用者に適用されます。

個人情報を取り扱う事業者は、Streetboardgame運営者　平川智章（以下「運営者」）です。本ポリシーにおける「利用者情報」は、本サービスに関連して取得・生成・保存される情報をいい、「個人情報」は個人情報の保護に関する法律第2条第1項に定める個人情報をいいます。

4. 他の利用者への公開・共有範囲

  • 理解度ボード：掲載は任意です。掲載に同意した利用者の表示名、一致した問題数、利用者が選択または入力したコメントを同じクイズの参加者へ表示します。自由入力コメントは、個人情報らしい内容や不適切な表現を自動検知するために処理します。掲載しない利用者は理解度ボードへ表示しません。
  • 主催者用回答管理：問題ごとの回答内容は、秘密の主催者用URLを持つ出題者へ表示します。主催者用URLは回答者へ公開しません。
  • ライブ配信：配信者が選択肢別人数の表示を有効にした場合、個人名を付けない集計人数を配信者と視聴者へ表示します。視聴者本人の回答・正誤・結果カードは当該視聴者に表示します。
  • 自作お題：掲載候補への送信に同意した問題文と選択肢は、運営者の審査・編集後に共通お題ライブラリで他の利用者へ公開する場合があります。掲載候補として送信しない問題は、この目的では公開しません。

問題文または選択肢から本名、学校名、SNS ID、電話番号、住所らしい文字列を検知した場合、掲載候補として保存せず、送信者へ修正を求めます。性的内容、いじめ、容姿攻撃または差別表現らしい内容は審査フラグとともに保存し、運営者が確認します。

5. YouTube API Services

本サービスはYouTube API Servicesを利用する場合があります。本サービスはYouTube、Googleまたはその関係会社が提供、後援、承認するサービスではありません。

公開チャンネル・動画の情報を取得して問題候補の作成に利用します。YouTuber本人がGoogle認証を選んだ場合は、本人が管理する過去1年の公開動画から、再生数を主軸に公開日の新しさも加味して優先した最大8本の字幕を取得し、実際の発言・場面を反映した問題候補の生成に利用します。Googleアクセストークンは処理後に失効させ、ログイン認証情報、パスワード、アクセストークンおよびリフレッシュトークンを保存しません。YouTube機能の利用にはYouTube利用規約およびGoogleプライバシーポリシーが適用されます。

利用者はGoogleセキュリティ設定で連携を解除できます。削除依頼を受けた対象データは、法令上保存が必要なものを除き削除します。
